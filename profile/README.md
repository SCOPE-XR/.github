<h1 align="center">SCOPE-XR: Seeing the Channel: Optimizing Perception-aware Environments for XR</h1>

<p align="center">
  <b>NSF VINES Track 2 · Award <a href="https://www.nsf.gov/awardsearch/showAward?AWD_ID=2554332">#2554332</a> · Sep 2026 – Aug 2029</b><br>
  🌐 <a href="https://scope-xr.github.io">scope-xr.github.io</a>
</p>

---

SCOPE-XR builds perception-aware wireless networks for multi-user extended reality (XR). The project combines on-device perception (pose, gaze, and scene geometry) with radio measurements to predict the wireless channel. It then uses those predictions to adapt network resources ahead of time through O-RAN–compliant software. The target applications are collaborative STEM learning and industrial safety training.

**All SCOPE-XR code is hosted in this organization.**
